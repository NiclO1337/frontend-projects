## Projects

### 1. Modern CV

A one-page, responsive CV website in the style of a modern Canva template,
with a dark navy sidebar and a light main column. It has a light/dark theme
toggle and a button to download the CV as a PDF.

- **Focus:** semantic HTML, CSS layout (Flexbox and Grid), responsive design
- **Built with:** HTML, CSS and a little vanilla JavaScript
- [Live site](https://frontend-projects-project1-modern-c.vercel.app/) · [README](project1-modern-cv-webpage/README.md) · [Testing](project1-modern-cv-webpage/TESTING.md)

### 2. Bun Intended

A multi-page website for a fictional burger restaurant in Stockholm, with a
dark "ketchup & mustard" theme. It has an image slider, a menu with a category
filter, a live "open now" badge, an allergens table and a validated booking
form.

- **Focus:** multi-page layout, Bootstrap, UX and JavaScript interaction
- **Built with:** HTML, CSS, Bootstrap 5.3 and vanilla JavaScript
- [Live site](https://frontend-projects-project2-modern-b.vercel.app/) · [README](project2-modern-business-website/README.md) · [Testing](project2-modern-business-website/TESTING.md)

### 3. Developer portfolio

My personal developer portfolio, built as a multi-page React app with a deep
dark blue theme and light-blue neon effects. It has a project list that can be
filtered by technology, a detail page for each project, a contact form that
really sends messages, light and dark themes, and automated tests.

- **Focus:** React, routing, reusable components, state and automated testing
- **Built with:** React 19, React Router, Vite, CSS Modules, Motion and Vitest
- [Live site](https://frontend-projects-phi-topaz.vercel.app/) · [README](project3-portfolio-website/README.md) · [Testing](project3-portfolio-website/TESTING.md)
